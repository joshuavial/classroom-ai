# ADR-0010: Six digit session code

Status: Accepted. Date: 2026-10-06.
## Context

Getting students in must take seconds and need no accounts.

## Decision

The teacher starts a session and gets a six-digit code. Students join with the code and a name. The teacher opens, pauses and closes the session. A student record lasts one session.

## Consequences

Anyone with the code can join under any name; the teacher sees the roster and can remove people. Students can't see conversations from earlier lessons. Accounts are a later increment.
